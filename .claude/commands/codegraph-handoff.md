# CodeGraph Handoff

Prepare or use a minimal handoff packet for delegated analysis.

Read:

```txt
.project-map/subagents.md
.project-map/handoff-packets/
.project-map/agents-manifest.json
```

Each handoff must include:

- mission;
- context in 5 to 15 lines;
- files allowed;
- files forbidden;
- commands allowed;
- expected output;
- success criteria;
- time/token limit;
- requirement to cite files read.

Never give a sub-agent secrets, generated logs, full repo context, or unrelated files.
