# codegraph:onboard

Génère un guide d'entrée projet (humain + amorçage IA).

## Quoi faire
1. Produire `.project-map/onboarding.md` : pitch, stack/structure, 5 fichiers
   clés (par fan-in), 2-3 flux principaux, conventions, surfaces sensibles,
   commandes utiles (voir spec-dev-experience.md E.1).
2. Court et actionnable : < 2 min de lecture, < 1500 tokens.

Voir references/specs/spec-dev-experience.md (E.1).
